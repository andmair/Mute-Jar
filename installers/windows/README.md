# Windows Single-File Installers

After the GitHub Actions workflow runs (triggered automatically on every commit), download **`installers-windows`** (or **`mutejar-installers-all-os`**) from **GitHub → Actions** to get:

- `Mute Jar_1.0.0_x64-setup.exe` (NSIS wizard)
- `Mute Jar_1.0.0_x64_en-US.msi` (Windows Installer package)

### Install
1. Double-click the `.exe` or `.msi` file.
2. Launch **Mute Jar** from the Start Menu.
