# ChromeOS Installation (1-Click PWA)

ChromeOS does not require a downloaded installer binary.

### Install
1. Open the Mute Jar web URL in Google Chrome on your Chromebook.
2. Click the **Install** icon in the Chrome address bar (or **Setup → Install App** in the top menu).
3. Right-click the Mute Jar icon on the ChromeOS Shelf and select **Pin**.
4. *(Optional)* Enable **Open on startup** under **ChromeOS Settings → Apps → Manage your apps → Mute Jar**.
