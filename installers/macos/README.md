# macOS Single-File Installer

After the GitHub Actions workflow runs (triggered automatically on every commit), download **`installers-macos`** (or **`mutejar-installers-all-os`**) from **GitHub → Actions** to get:

- `Mute Jar_1.0.0_universal.dmg` (runs natively on Apple Silicon M1–M4 and Intel Macs)

### Install
1. Double-click the `.dmg` file.
2. Drag **Mute Jar** into your **Applications** folder.
3. On first launch, approve microphone permission under **System Settings → Privacy & Security → Microphone**.
