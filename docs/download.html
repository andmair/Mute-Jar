Verify Download Integrity (SHA-256)

Compare your downloaded installer against installers/SHA256SUMS.txt or browse all tagged builds on GitHub Releases. 

# macOS / Linux
shasum -a 256 "Mute Jar"*
sha256sum -c SHA256SUMS.txt --ignore-missing

# Windows PowerShell
Get-FileHash ".\Mute Jar*" -Algorithm SHA256

Code Signing & First-Launch Tips

  • Windows: Free Windows code signing provided by SignPath.io, certificate by SignPath Foundation (when configured in CI). Before onboarding, verify the SHA-256 hash above and click More info → Run anyway.
  • macOS: Free builds use Apple ad-hoc signing. If Gatekeeper flags the app on first launch, right-click Mute Jar.app → Open or run xattr -rd com.apple.quarantine "/Applications/Mute Jar.app".
